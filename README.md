## The game and the idea

CONTROL Resonant follows Dylan Faden through a transformed Manhattan. The proposed module is a prerelease plan for combat assistance and ability experimentation, with all game-state controls deferred until the PC release can be tested.

**Game release status:** Upcoming - scheduled for 24 Sep, 2026. Checked against the [Steam listing](https://store.steampowered.com/app/3669870/) on 2026-09-05.

## Proposed assistance options

These are development targets. Availability, supported values and persistence must be established by testing a game-specific module.

| Area | Planned behaviour |
|---|---|
| **Combat assistance** | Research bounded damage assistance once the released game's combat values are understood. |
| **Ability profiles** | Plan readable ability configurations without assuming an unconfirmed skill tree or resource model. |
| **Encounter pacing** | Investigate adjustable practice speed and check its effect on animations and scripted events. |
| **Progression budgets** | Prepare a module interface for verified progression resources; exact resource names remain unassigned. |
| **Practice snapshots** | Explore encounter restoration after the released save structure and checkpoint behaviour are documented. |
| **Build-specific support** | Require a tested game version beside every eventual feature and keep unsupported options unavailable. |

## A practical use case

After the PC release, a player could rehearse an encounter with limited assistance and reduce it on later attempts. This package describes that experience without claiming that an operational module already exists.
